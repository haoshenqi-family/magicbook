# learning · 每日学习（L1 用户文档）

## 这是什么

「每日学习」页（导航 Settings → Daily Learning）是科学学习的复习中枢：你在阅读中标记的生词、听写里错的词会按**间隔重复**算法安排复习——快忘的时候刚好出现，每次作答都是一次记忆提取。

## 能做什么

- **复习队列**：到期生词逐张卡片复习，刚学过、昨天学过的词优先出现；题目按熟练度自动升级——
  - **辨析题**（初学）：给出中文释义，从 4 个英文单词里选出正确的那个；
  - **回忆题**（复习期）：看中文释义自己回想单词，点「揭示」对照；
  - **拼写题**（熟练后）：看中文释义把单词拼出来，系统判定对错。
  - 词卡上还会显示「最近在本书第几章遇见过它」的原文语境与遇见次数。
- **四档评分**：每次作答按 忘记 / 难 / 想起 / 轻松 自评或自动判定，算法据此安排这个词下次出现的时间（10 分钟到数周）。
- **今日计划**：按你设置的每日时长展示四股时间预算（阅读输入 / 词汇学习 / 说写输出 / 流利训练）与今日新词。四股行实时显示**今日已入账 vs 预算**（如「阅读输入 10/5min」）：在阅读器里实际阅读的时长（页面可见且有翻页/滚动操作才计）、划词查词、复习作答、口语/写作/复述、跟读/计时重读都会自动折算进对应各股（2026-10-11 起，统计暂不可用时显示 –）。
- **学习统计**：今日复习进度（x/20，达标后可继续加练，上不封顶）、明日预告、已掌握数、近 7 天保持率。
- **选书难度匹配**：按你的词汇量自动选定分级书架（阶 1–6，六阶爬梯），再从书架内逐本估算生词密度，标出 轻松读 / 正合适 / 挑战读 三档与高频生词预览；推荐书可点击直达书库详情页。估算在后台进行，打开页面稍等片刻会自动补上（2026-10-11 起，先选架再推荐）。

## 说与写（2026-10-11 起）

导航 Settings → **Speaking & Writing**，三个面板，全部计入每日四股的「说与写」：

- **写作工坊**：自由写作或按 A2–C1 等级出题（可结合你在读的书）。提交后 AI 批改——总体评价 + 逐句点评 + 「母语者会怎么写」的升级表达 + 四维评分（语法/词汇/连贯/任务完成度）；按批改修订再提交，还能看到两稿的「进步确认」。
- **AI 口语陪练**：五个场景（咖啡店 / 面试 / 旅行 / 闲聊 / 聊在读的书）开聊，教练先回应内容再给语言反馈（先鼓励、再纠错、后给更地道的说法）；宽松 / 标准 / 严格三档教练风格。结束出会话报告：小结、进步点、你用得好的词、全部纠错。历史会话可点开回放。P2 阶段用打字代替开口（ASR 语音输入待接入）。
- **复述训练（4-3-2）**：粘贴一段读过的英文，用 4→3→2 分钟的递减时限复述三遍（P2 阶段打字转写）。系统自动算每轮的语速（WPM）、填充词次数、词汇多样性，结束 AI 解读三遍的变化并给训练建议。

## 使用建议

- 释义题干依赖单词详解缓存：查过的词立即有完整题目；没查过的词先以「亮词自评」模式复习，在 MagicLens 扩展里划词查过一次后自动升级为完整题型（2026-10-09 起阅读器内置划词下线，查词统一走扩展）。
- 阅读时随手标记生词，复习队列会自动滚动起来；无需手动录入。
