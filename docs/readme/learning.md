# learning · 每日学习（L1 用户文档）

## 这是什么

「每日学习」页（导航 Settings → Daily Learning）是科学学习的复习中枢：你在阅读中标记的生词、听写里错的词会按**间隔重复**算法安排复习——快忘的时候刚好出现，每次作答都是一次记忆提取。

## 能做什么

- **复习队列**：到期生词逐张卡片复习，刚学过、昨天学过的词优先出现；题目按熟练度自动升级——
  - **辨析题**（初学）：给出中文释义，从 4 个英文单词里选出正确的那个；
  - **回忆题**（复习期）：看中文释义自己回想单词，点「揭示」对照；
  - **拼写题**（熟练后）：看中文释义把单词拼出来，系统判定对错。
  - 词卡上还会显示「最近在本书第几章遇见过它」的原文语境与遇见次数。
- **四档评分**：每次作答按 忘记 / 难 / 想起 / 轻松 自评或自动判定，算法据此安排这个词下次出现的时间（10 分钟到数周）。
- **今日计划**：按你设置的每日时长展示四股时间预算（阅读输入 / 词汇学习 / 说写输出 / 流利训练）与今日新词。
- **学习统计**：今日复习进度（x/20，达标后可继续加练，上不封顶）、明日预告、已掌握数、近 7 天保持率。
- **选书难度匹配**：按你的词汇量给书架每本书估算生词密度，标出 轻松读 / 正合适 / 挑战读 三档与高频生词预览（首次打开某本书的详情后开始计算）。

## 使用建议

- 释义题干依赖单词详解缓存：查过的词立即有完整题目；没查过的词先以「亮词自评」模式复习，在 MagicLens 扩展里划词查过一次后自动升级为完整题型（2026-10-09 起阅读器内置划词下线，查词统一走扩展）。
- 阅读时随手标记生词，复习队列会自动滚动起来；无需手动录入。
