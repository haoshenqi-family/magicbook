# credit 模块（积分与订阅）· 用户手册

## 能做什么

- **积分账户**：查看余额、累计发放/消耗；AI 功能按 token 用量扣积分（1 千 token = 10 积分）。
- **积分明细**：获取与消耗统一列表（充值/赠送/AI 功能名/模型/日期筛选），汇总占比一目了然。
- **积分充值**：支付宝当面付扫码充值（档位可选），下单→扫码→轮询自动开通。R205 起档位基础兑换率为 10 元=1000 / 99 元=2 万 / 999 元=50 万积分；**限时倍率活动**期间按倍率加成（当前内测 ×10），卡片显示「内测 ×N」角标、划线基础到账（如「50万 积分」）与倒计时。
- **订阅**：查看当前订阅与有效期（TeslaMate 托管等订阅能力的基础）。
- **成就**：读书/学单词/打卡三维成就徽章，查看进度、解锁、领取积分奖励。
- **管理员调整**：管理员账号可见积分调整面板（正负均可，需填原因，落流水）。R243 起正数发放可勾选【同时发送到账通知】，并填写最多 500 字的纯文本正文；用户会在站内信中收到积分到账记录。负数调整会禁用并清空通知选项。
- **管理员发布活动**：管理员账号在积分页可发布充值倍率活动（起止时间 + 整数倍率 1–100，时间按东八区解释）。**活动发布后不可修改或撤销**，时间与既有活动重叠会被拒绝，发布前有二次确认。

## 谁在用

站内个人页/积分页；消耗积分的 AI 功能（翻译、详解、伴读等）。
