# reading 模块（阅读器）· 用户手册

## 能做什么

- **多格式阅读**：EPUB / PDF / TXT 在线阅读。**EPUB 的阅读位置按账号记忆**（换电脑、换浏览器也能回到上次读到的一页，如 37/125）；PDF / TXT 目前仍按本机浏览器记忆。
- **划词查词（装了 MagicLens 就交给扩展，没装就用站内自带）**：选中单词或段落后给出释义、发音、「认识 / 生词」标记与六板块单词详解（基本意思/词源/搭配·用法·习语/变体衍生/同反义词/俚语冷知识）；详解内容长时面板内滚动，词目与关闭按钮（✕）滚动期间常驻面板顶部。[MagicLens 词镜](https://github.com/haoshenqi-family/magiclens) 浏览器扩展（v0.8.6 起）会在页面上声明「这条能力我接了」，阅读器读到就自动隐藏自己那份，避免同页两个气泡、一个生词两条波浪线；**没装扩展、扩展版本过旧、或你刚把扩展的高亮开关关掉时，阅读器的内置划词与生词波浪线照常可用**，不需要装扩展也能查词。生词本、学习数据两种入口写回同一份，与 moon-well 互通。
- **段落翻译**：鼠标移到段落上点「译」，译文直接显示在该段下方，再点一次收回。
- **段落 AI 批注**：段落旁「✨」生成背景/典故讲解。
- **朗读**：段落文字转语音朗读；同一段落重听零等待（音频按段落长期保留，不清理）。**跟伴读说「读这一段」**也行（R170）：AI 伴读合成好之后播放器直接取现成音频，同一次朗读只扣 1 积分、重复播放不再扣（再让 AI 读一遍算新的一次）；伴读发起的朗读没有书籍上下文，属临时音频，保留 7 天后自动清理。**整本连播**：标题栏「▶」从当前阅读位置起按顺序逐段朗读整本书——听一段自动接下一段、章末自动翻章续听、随时暂停/继续/停止，正在读的段落高亮且视图自动跟随；没听过的段落首次合成稍等几秒，听过的永久缓存秒开。**整本预生成**（管理员）：书详情页可提前把整本书的朗读音频逐段合成好，之后所有读者首听即秒开；批次页实时看进度、可随时停止或重试。重试会把「卡住没动」的批次原地接着跑（已合成的段不重复花钱、进度不清零），批次也能在书详情页再次点击时自动续跑。
- **整页 / 整本翻译**：当前页批量翻译；整本书翻译在书库发起，阅读器内查看进度。
- **新概念课级音频**：新概念英语书配套课级音频播放页（课文原文 + 音频同步）。
- **阅读主题**：浅色/深色/羊皮纸/琥珀/纯黑 5 个内置主题保存在账号里，换设备打开阅读器自动跟随；自定义颜色只留在本机，不同步。主题也可在个人页 `/me` 直接选。
