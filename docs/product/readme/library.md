# library 模块（书库）· 用户手册

## 能做什么

- **首页（`/home`）**：登录后默认落点，从上到下四块——**继续阅读**（最近读过的书，带 `37/125` 或百分比，一下点开回到原位）、**今日计划**（待复习词数与待完成写作篇数，点进学习页）、**按难度阶推荐**（按「阶N」书架分组，每阶给几本没读完的）、**随机发现**（原首页的随机书墙）。某一块没有数据时整块不显示。管理员可在「编辑配置」里取消勾选「登录后进入新首页」，让登录落点回退到原书库首页。
- **书架**：浏览、搜索、按分类/标签筛选 Calibre 书库中的图书。
- **阅读难度入口**：书墙上方直接显示当前档位（如「3 - CET4」），点「修改」两步内进入偏好设置调整；档位决定阅读时哪些词被标为生词。
- **书籍详情**：元数据一览 + 内容速览——出版日期诚实标注（书目未标出版日时显示「导入于」）、语言按书目声明展示并标「双语」、难度阶标签（标签/书架/系列映射，未分级明示）；已加入的书架显示为可移除芯片；登录用户默认均可「在线阅读」（整本翻译/朗读/单词详解为管理员工具）；**已归档的书仍可打开详情并正常显示内容速览**；账号若被单独关闭阅读权限，页面会明确提示找管理员开通「View」，而不是只返回 403。**缓存齐备标识**：一本书的整本翻译、整本朗读、全文单词详解三项缓存都备齐过时，详情页会显示「低成本学习」总标，并逐项列出已缓存的范围（悬停可看段数/词数）——翻译与查词命中缓存不额外计费、朗读按缓存命中 1 积分/段，读者据此能看出「这本书学起来便宜」。
- **无封面占位**：书目没有封面时显示统一的 magicbook 品牌封面，不再出现白底黑字「Cover not available」。
- **上传与导入**：上传电子书入库（EPUB/PDF/TXT 等，自动解析）；Halo 站点的 Markdown 文章可经连接器一键成书（可同时触发整本翻译）。
- **下载与同步**：图书下载；OPDS 目录供电子书阅读器订阅；Kobo 设备同步。
- **元数据管理**：编辑书名、作者、封面、标签等元信息。
- **整本翻译**：对当前书一键发起整本翻译（按章节拆任务走后端队列，完成后阅读器内段落自动呈现译文；支持查看进度、取消、失败重试）。进度条显示在书籍详情页的「整本任务」区域，明确标出当前是「整本翻译」「整本朗读」还是「全文单词详解」，并显示进行中、已完成、有失败段落或已取消。
- **后台任务不随页面请求中断**：整本任务在独立后台会话中执行，刷新页面或切换详情页不会关闭正在执行的批次；若进程重启后仍有待跑段落，进度条会显示「继续」，点击后从断点续跑，已完成段落与对应缓存继续复用。

## 谁在用

所有站内用户；OPDS/Kobo 面向外部阅读器设备。
