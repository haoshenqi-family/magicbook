# companion 模块（AI 伴读）· 用户手册

## 能做什么

- **围绕当前书对话**：阅读页打开 AI 伴读抽屉，就当前书内容提问（书名/章节/当前页文本自动作为上下文）。
- **状态可读（R215）**：点发送即出现「思考中 · N 秒」计时，首个字到达后自动替换。
- **悬浮球（R223）**：右下角伙伴按钮是透明头像悬浮球（iPhone 悬浮球式）：可拖拽、自动吸附左右边缘；鼠标悬停时弹出 4–5 个快捷气泡——「对话」固定**恒在第一位且不可删除**（R234），其余（翻译 / 朗读 / 书签 / 学习页 / 书库 / 我的）在 `/buddy` 页勾选配置，默认 翻译 + 朗读 + 书签；全站登录页均可用（R220）。
- **工具调用**：AI 可调用查词、翻译等工具，界面以「工具芯片」展示调用过程与结果。
- **按需加载伴读指南（moon-well R214 / magicbook R228）**：涉及阅读、翻译、查词、词汇、学习计划、朗读、积分或伙伴的问题，AI 可先取一份随服务发布的 MagicBook 全功能伴读指南，再给出具体页面、操作步骤与边界。指南按需读取，不占每轮对话；它只提供说明，**不会让 AI 获得点按钮、改设置、下单或启动整本任务的新权限**。
- **站内链接直达（R233）**：回答里给出的 MagicBook 页面路径（如 `/me`、`/credits`、`/book/252`）或本站绝对地址会显示为链接，点击在新窗口打开；仅站内地址可点击，外部网站、代码块与不安全协议保持纯文本。
- **说话提问（R227）**：输入框左侧麦克风，点一下开始说、再点一下停止；说的话会转成文字填进输入框，**改完再按发送**。任何页面都能用（站内页与阅读页一致）。转写按录音时长计费：22 秒 = 1 积分，不足 22 秒也按 1 积分收（一句提问约 0.01 元）。
- **朗读回复（R227）**：每条回答底部有「朗读本条」，点一下念给你听，再点一下停止；长回答会分段念完并显示进度。**不点不扣**；重听已念过的内容 1 积分/段，首次让 AI 真正合成按字数计（50 字符 = 1 积分，约合 2 元/万字符）。
- **跨书记忆**：AI 记住你的偏好与背景（如英语水平），跨书、跨会话复用；会话可改名、可删除。
- **流式回复**：回答逐字输出，生成中显示占位提示。
- **聊天里不显示用量（R232）**：每条回答下面是干净的正文，不挂「tokens 输入/输出」这类灰字。用量照常记录、照常扣积分，需要核对时去【设置】【积分】的消耗明细看（「原因」列写明这一笔消耗了多少 token）。
- **伙伴（buddy）**：伙伴是 AI 阅读按钮上的那张脸——领取、切换只改变外观，**不会改变 AI 作为英语老师的角色**。`/buddy` 管理花名册，个人页 `/me` 只展示当前使用的伙伴并可跳转管理。

## 谁在用

阅读页右侧伴读抽屉与悬浮伙伴按钮；同一能力也以 Chrome 扩展 magiclens 的形态用在任意网页。
