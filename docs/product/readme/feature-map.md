# MagicBook 功能地图（L1）

> 这张地图回答三个问题：**有哪些功能、功能属于哪里、应该从哪里进入**。
> 范围只包括 MagicBook 在 Calibre-Web 基础上新增或重新组织的用户能力；Calibre 原生的
> 书目、作者、分类、书单等基础浏览能力不重复展开。

## 1. 五域总览

登录后，所有页面先归入五个一级域。一个页面只属于一个域，用户不需要先理解内部模块名。

| 一级域 | 主要任务 | 典型入口 |
| --- | --- | --- |
| 首页 | 今天读什么、继续上次阅读、查看今日计划 | 继续阅读、分级推荐、随机发现 |
| 书库 | 找书、看书目信息、进入阅读器 | 书架、搜索、书籍详情、阅读页 |
| 学习 | 完成当天的词汇与英语练习 | 学习中枢及八个学习功能 |
| 账号 | 管理个人资料、偏好、资产、消息与学习数据 | 资料、伙伴、站内信、阅读设置、积分、成就、导出 |
| 管理 | 管理员治理用户、内容、积分与系统 | 用户、站点、任务、日志和系统配置 |

> **伙伴不是第六个一级域**。伙伴是 AI 伴读的入口和外观，归在「账号 → 伙伴与 AI 伴读」；
> 全局悬浮伙伴和阅读器里的 AI 抽屉都复用同一套对话能力。

## 2. 按任务找功能

| 我想…… | 先去哪里 | 还可以从哪里进入 |
| --- | --- | --- |
| 接着上次继续读 | 首页 → 继续阅读 | 书库中的最近阅读状态 |
| 找一本适合当前水平的书 | 首页 → 分级推荐 | 学习 → 选书难度匹配 |
| 调整生词判定难度 | 账号 → 阅读与词汇 | 书墙顶部的难度入口 |
| 做词汇量测试或细筛 | 账号 → 阅读与词汇 | 学习中枢相关卡片 |
| 读一段、翻一页或整本翻译 | 阅读器段落工具栏 | AI 伴读可执行对应动作 |
| 查词、标记生词、看单词详解 | 阅读器划词气泡 | 安装 MagicLens 时由扩展接管 |
| 做复习、听写、口语、写作 | 学习中枢 | 首页今日计划和欠账提示 |
| 和 AI 围绕当前书对话 | 阅读器 AI 抽屉 | 账号 → 伙伴与 AI 伴读、悬浮伙伴 |
| 查看或领取站内信 | 悬浮伙伴信封 | 账号 → 站内信、设置菜单 |
| 查看积分、充值或买积分卡 | 账号 → 积分 | AI 余额不足提示 |
| 修改用户名或邮箱 | 账号 → 资料与身份 | 「前往统一账号中心」 |
| 管理用户、站点或运营工具 | 管理 | 仅管理员可见 |

## 4. 账号页索引（A1–A7）

账号页按一个任务一页组织，页头只用纯文字导航，不用功能卡片堆目录。

| 编号 | 页面 | 主要任务 | 路由 |
| --- | --- | --- | --- |
| A1 | 资料与身份 | 用户名、邮箱、统一账号中心、OIDC 绑定、语言 | `/me` |
| A2 | 伙伴与 AI 伴读 | 伙伴选择、装备、快捷动作、打开 AI 抽屉 | `/buddy` |
| A3 | 站内信 | 收件箱、展开已读、全部已读 | `/mail` |
| A4 | 阅读与词汇 | 难度、词测、主题、使用引导 | `/reading/settings` |
| A5 | 积分 | 余额、充值、积分卡、订阅、明细 | `/credits` |
| A6 | 成就 | 进度、解锁、领取 | `/achievements` |
| A7 | 我的学习数据 | 创建导出、查看进度、下载 | `/me/export` |

## 5. 管理页索引（M1–M13）

管理域只对管理员显示；每个页面承担一个治理任务。

| 编号 | 页面 | 主要任务 | 路由 |
| --- | --- | --- | --- |
| M1 | 用户与权限 | 用户列表、角色、阅读 / 下载权限 | `/admin/usertable` |
| M2 | 站点与注册 | 站点、注册、匿名访问和登录配置 | `/admin/config` |
| M3 | 整本翻译 | 发起和查看整本翻译任务 | `/translate-all` |
| M4 | 全文单词详解 | 选书、预览、入队 | `/word-detail-batch` |
| M5 | LLM 任务中心 | 手动执行、队列监控、失败恢复 | `/llm-tasks` |
| M6 | 积分治理 | 调整、充值活动、批量发卡 | `/admin/credits` |
| M7 | 运营站内信 | 单发 / 群发、发送历史、撤回 | `/admin/mail` |
| M8 | UI 配置 | 书架视图与界面配置 | `/admin/viewconfig` |
| M9 | 数据库配置 | Calibre 数据库连接 | `/admin/dbconfig` |
| M10 | 邮件服务器 | SMTP 与发信配置 | `/admin/mailsettings` |
| M11 | 计划任务 | 元数据、缩略图等定时任务 | `/admin/scheduledtasks` |
| M12 | 日志 | 应用日志查看与下载 | `/admin/logfile` |
| M13 | 调试 | 调试信息下载 | `/admin/debug` |

## 6. 维护规则

- 新增、删除或移动用户功能时，先更新本文件，再更新对应模块手册。
- 本文件是功能树的**唯一用户视角清单**；L3 实现说明只保留页面归属、边界和测试要求，不复制整棵树。
- 叶子必须是用户能理解和操作的小功能，不能把「一个页面」误当成「一个功能」。
- 路由变化必须同步 A1–A7、M1–M13 索引；权限差异必须明确写“仅管理员”。
- Calibre 原生能力只有在被 MagicBook 重新组织或增加入口时才进入本图，不把上游全部能力抄进来。
