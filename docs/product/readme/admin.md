# admin 模块（管理）· 用户手册

## 能做什么

- **管理 L2 按任务拆页**：页头只显示一组纯文字导航，共 13 页——用户与权限、站点与注册、整本翻译、全文单词详解、LLM 任务中心、积分治理、运营站内信、UI 配置、数据库配置、邮件服务器、计划任务、日志、调试。顶栏“管理”直接进入“用户与权限”；旧 `/admin/view` 只做兼容跳转。
- **管理员运营站内信（R250）**：进入「运营站内信」，自由填写标题与纯文本正文，发给指定用户或全体用户；可预览精确收件人数与卡片，单次最多 5000 人。发送历史支持整批撤回，撤回后邮件从所有收件箱消失且不可恢复，审计保留。
- **积分治理**：进入独立 `/admin/credits`，完成积分调整、充值倍率活动和批量发卡；普通用户的 `/credits` 不再渲染这些表单。

- **LLM 任务手动执行**（管理员）：管理 L2「LLM 任务中心」`/llm-tasks`——选择供应商、模型、并发数与本批上限，手动消费积压的翻译/详解等队列任务；实时看进度（已认领/成功/失败/执行中），可中途停止，可在队列排空后重放失败任务（不会重复计费）。与「自动执行」模式互斥。
- **LLM 队列监控**（管理员，R130）：「任务执行」页面下半部——队列总览（按调用方分组的计数、近 24 小时吞吐、滞留预警）、失败原因分类（十类分桶 + 恢复方式）、任务查询与详情（含输入/输出全文，默认截断可展开）、恢复（先生成只读预案，二次确认后才重发失败任务；重发消耗真实模型配额）。
- **用户与权限**：上游 Calibre-Web 自带的用户管理、匿名访问、注册开关等站点管理；它是管理域 M1 主入口。
- **登录管理**：Authentik（OIDC）统一登录；邀请制注册入口（邀请链接由管理员轮换下发）。
- **新账号角色**（R211 / R225）：自助注册（含邀请链接）的账号**一律是普通读者**——按站点「新用户默认角色」建号，并自动具备在线阅读能力；即使该默认角色里勾了管理员位也不会生效。下载仍是独立权限，不会随阅读一起自动开放。**管理员只能由站长在「用户管理」里手动赋予**，登录链路上没有任何自动提权开关。存量账号的角色不受影响；历史遗留的超管、缺阅读权限的普通账号，分别用仓库脚本先出清单再点名修正。
- **AI 伴读配置**：伴读能力开关（配置收敛在 moon-well 侧 Nacos，本项目只读状态）。

## 谁在用

站点管理员。
