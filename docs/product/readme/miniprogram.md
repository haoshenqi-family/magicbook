# miniprogram · 微信小程序 · 用户手册

## 这是什么

magicbook 在微信里的入口：**AI 伴读、每日复习、词汇量测试，外加一页「我」放账号与学习数据**。
打开小程序**默认落在「复习」**（tab 第一项），因为这是最高频的一件事。

它不读书——阅读、翻译、朗读、生词本与书页里的 AI 伴读仍然在网页端
`magicbook.haoshenqi.top`（「我」页有一条复制链接的入口）。
小程序里的「AI」tab（R283 起文案为「AI」，功能名仍「AI 伴读」）是**通用对话**：
不绑定任何书或网页，直接问英语学习上的问题，
也可以自然闲聊。生词本页已于 R280 下掉，网页端生词本与数据不受影响。

## 能做什么

- **每日复习（首页）**：拉取今天到期的词，最多一轮 20 张。题型按你的熟练度自动切换——
  **四选一**（看中文释义挑出英文词）、**拼写**（看释义拼出来）、**回忆**（看中文释义自己回想，再揭示答案）。
  每张卡答完按「忘记 / 很难 / 想起 / 轻松」四档自评，系统据此安排下次出现的时机。
  卡片上方能看到今日进度（x/20）；完整的到期数、明日到期、复习中、已掌握与近 7 天保持率在「我」页。
  中文释义取词条详解缓存：命中就拿它当题干；某个词还没缓存详解时，卡片直接亮出英文词按印象自评
  （R290 起；此前这类卡没有题干，只有一句「看下面的提示」）。
- **AI 伴读（R280）**：第二个 tab（R283 起底栏文案为「AI」）。打开是一段欢迎语加三个快捷问题，点一下就能直接发问；
  也可以自己输入。回答逐字出现，生成中显示「正在思考」；AI 查词或查证时会变成「正在查证」。
  适合问词义、语法、地道表达、读书方法、选书与学习计划，也能自然闲聊。
  点右上角「新会话」清掉当前界面上的对话（历史仍保存在账号里，可在网页端查看）。
  - **这里没有书**：小程序不会把某本书、某一页或某段网页正文当作上下文，也不会凭空编一个书名；
    想就当前读的内容提问，请用网页端阅读器里的 AI 伴读抽屉。
  - **会话跟着账号走**：下一轮会带上 `conversationId`，换设备或重进小程序能接着聊。
  - **闲聊默认不写长期记忆**：只有你明确让 AI「记住某事」时才会沉淀偏好，与网页场景同一隐私口径。
- **词汇量测试**：3–4 分钟自适应测试，屏幕只出现英文词与例句，只答「认识 / 不认识」。
  交卷前可以勾选「把这次不认识的词收进网页端生词本」；报告给出估算词汇量、置信区间、各频段
  掌握度，并推荐一个阅读难度档位，可一键应用到账号（与网页端同一份设置）。
- **我**：账号入口（绑定邮箱 / 退出）+ 主站链接 + 学习数据。学习数据含今日四股（阅读输入 / 词汇学习 / 说与写 / 流利度）的预算与已入账、
  复习摘要、近 7 天逐日走势、最近一次词汇量。微信临时账号的绑定提示条也在这一页顶部。

## 第一次使用

1. 微信里打开小程序 →「微信一键登录」，**不用注册、不用输密码**，直接就能用。
2. 首次登录会为你创建一个**微信临时账号**：功能全部可用，但没有找回途径——
   换手机或卸载小程序就找不回来了。「我」页顶部会有一条提示，点它进「账号」页。
3. 在「账号」页绑定邮箱即可正式化：
   - 这个邮箱**没有**对应的网页端账号 → 邮箱写到当前账号上，账号转正；
   - 这个邮箱**就是**你网页端账号的邮箱 → 小程序账号会自动并入那个账号，
     两边的学习记录合成一份（网页端数据为准，临时账号里的数据会被丢弃，
     提交前会明确告诉你有什么、并要你确认）。
4. 如果你不想产生临时账号，登录页下方还有「我已有账号，用邮箱登录」：
   填网页端账号使用的邮箱 → 收一次验证码 → 直接登进那个账号，同时把当前微信绑上去。
   **全程不需要密码**。
   - 该邮箱还没有账号时会明确提示，用上面的「微信一键登录」即可创建。
   - 账号在网页端从没填过邮箱的，需要先在网页端补上邮箱再来。

## 账号与绑定

底部 tab「我」→ 顶部身份卡（点进去就是账号页），能看到当前账号状态：

| 状态 | 含义 | 该做什么 |
|---|---|---|
| 微信临时账号 | 自动创建、未绑邮箱 | 绑定邮箱（否则换设备即丢） |
| 已绑定邮箱 | 正式账号 | 无；网页端用同一邮箱登录看到的是同一份数据 |

页面上还有「退出登录」。退出只清本地登录态，账号与数据都不受影响。

「我」页顶部还有一张 **MagicBook 网页版** 卡片：小程序不能直接调起浏览器，
所以点它是「复制链接」，粘到浏览器地址栏即可继续阅读、查看生词本。

## 一些说明

- **生词本在网页端**：R280 起小程序不再有生词本页；阅读时标过的词、单词释义与标记管理
  都在网页端。词汇量测试里「收进生词本」收的也是网页端那份数据。
- **网页端生词本的释义要先查过才有**：释义来自单词详解缓存，没查过的词显示「暂无释义」，
  小程序不会因此消耗积分去生成。
- **听辨类题目在本小程序里不出**：音频播放需要带登录凭证，小程序的音频组件做不到；
  这类题型（听音选词、听音拼写）在网页端可用。
- **AI 伴读不朗读、不播工具轨迹**：回答以文字逐字出现，工具调用过程只显示状态提示；
  自动播放音频会让人措手不及，也不适合小程序的前后台切换。
- 小程序只读不写正文——阅读时长等「阅读输入」数据只能在网页端产生，所以这一股在小程序里
  通常显示为 0。
- 换微信或换账号：在新微信里登录后，用它绑定同一个邮箱即可并回原账号（原绑定会让路）；
  也可以在「账号」页重新绑定邮箱。

## 工程信息（换环境要改的地方）

| 项 | 值 | 备注 |
|---|---|---|
| AppID | `wx7b31b435be6beae3` | 正式号。写在 `project.config.json`，必须与后端 `app.wx.appid` **完全一致** |
| 后端 | `https://moon-well.haoshenqi.top` | `config.js` 的 `baseUrl`；需在该 AppID 的 **request 合法域名**里 |
| 网页版 | `https://magicbook.haoshenqi.top` | `config.js` 的 `siteUrl`；只在「我」页作为「复制链接」使用 |
| 导入目录 | `magicbook/miniprogram` | 微信开发者工具「导入项目」选这一层 |

两处容易踩的坑：

- **合法域名是按 AppID 存的**：换 AppID 后旧号的域名白名单不会继承，需要在「开发管理 →
  开发设置 → 服务器域名」重新添加 `https://moon-well.haoshenqi.top`，否则真机报「不在合法域名列表」。
  开发期可先勾「不校验合法域名」。
- **openid 也是按 AppID 分的**：换号后同一个微信会拿到新的 openid，微信侧无法把它与旧账号关联。
  换号后第一次登录会落到一个新账号，需要用登录页的「我已有账号，用邮箱登录」认领回原账号。

## 请求失败怎么查

先记住一条：**开发者工具里的「不校验合法域名」只对开发版有效**。勾上它调试正常，
不代表体验版/线上能用——真机与体验版一律按小程序后台的白名单严格校验。
所以「本地好好的、发布后全部请求失败」几乎总是白名单问题。

排查顺序：

1. **看真实原因**：体验版右上角 `···` →「打开调试」→ 退出重进，vConsole 里会有一条
   `[api] 请求失败 <路径> appid=wx… request:fail ...`，那串 `errMsg` 和 AppID 就是答案。
2. `url not in domain list` → 去小程序后台「开发管理 → 开发设置 → 服务器域名」，
   把 `https://moon-well.haoshenqi.top` 加到 **request 合法域名**。
   注意：**白名单按 AppID 存**，换过 AppID 要重新加；域名必须已备案、必须 HTTPS。
3. `timeout` → 网络慢或服务未响应，重试即可（服务端正常时单次约 0.2s）。
   AI 伴读的回答是流式的，等待时间可以比普通请求长，界面会一直显示「正在思考」直到首字到达。
4. `ssl` / `handshake` → 证书链或系统时间异常；老旧 Android 对较新的根证书可能不信任。
5. 以上都对仍失败 → 手机换 4G/换 Wi-Fi 各试一次，排除局域网 DNS 劫持。
