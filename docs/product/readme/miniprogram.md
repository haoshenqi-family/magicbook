# miniprogram · 微信小程序（工具型）· 用户手册

## 这是什么

magicbook 的**词汇工具**在微信里的入口：生词本、每日复习、词汇量测试、学习数据四件事。
它不读书——阅读、翻译、朗读、AI 伴读仍然在网页端 `magicbook.haoshenqi.top`。

## 能做什么

- **生词本**：网页端阅读时标过的生词，在这里按「全部 / 生词 / 复习中 / 已掌握」翻页查看，
  可按词前缀搜索；点一个词就能就地改标记（标认识 / 标回生词）。每条显示中文释义、入库来源
  （手标 / 听写 / 测试）、阅读中遇见的次数与最近一次学习日期。
- **每日复习**：拉取今天到期的词，最多一轮 20 张。题型按你的熟练度自动切换——**四选一**
  （看中文释义挑出英文词）、**拼写**（看释义拼出来）、**回忆**（自己回想后揭示答案）。
  每张卡答完按「忘记 / 很难 / 想起 / 轻松」四档自评，系统据此安排下次出现的时机。
  首页能看到今日进度（x/20）、到期数、明日到期、复习中、已掌握与近 7 天保持率。
- **词汇量测试**：3–4 分钟自适应测试，屏幕只出现英文词与例句，只答「认识 / 不认识」。
  交卷前可以勾选「把这次不认识的词收进生词本」；报告给出估算词汇量、置信区间、各频段
  掌握度，并推荐一个阅读难度档位，可一键应用到账号（与网页端同一份设置）。
- **学习数据**：今日四股（阅读输入 / 词汇学习 / 说与写 / 流利度）的预算与已入账、
  复习摘要、近 7 天逐日走势、最近一次词汇量。

## 第一次使用

1. 微信里打开小程序 →「微信一键登录」。
2. 第一次会要求输入**网页端 magicbook 的账号密码**——这是把你的微信绑到已有账号上，
   不会新建账号。绑定之后再进来就不用输密码了。
   账号如果从来没有设置过密码（一直用统一账号中心登录），需要先在网页端设置一次密码。
3. 绑定后进「生词本」页，数据与网页端是同一份。

## 一些说明

- **释义要先在网页端查过才有**：生词本的释义来自单词详解缓存，没查过的词显示「暂无释义」，
  小程序不会因此消耗积分去生成。
- **听辨类题目在本小程序里不出**：音频播放需要带登录凭证，小程序的音频组件做不到；
  这类题型（听音选词、听音拼写）在网页端可用。
- 小程序只读不写正文——阅读时长等「阅读输入」数据只能在网页端产生，所以这一股在小程序里
  通常显示为 0。
- 换微信或换账号：目前需要在新微信里重新绑定一次（原账号的绑定会被覆盖）。
