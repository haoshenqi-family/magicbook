# learning · 每日学习（L1 用户文档）

## 这是什么

「每日学习」页（顶部导航 Daily Learning）是科学学习的中枢：一页看到今天的四股时间预算、
复习欠账和本周走势，并从循环卡片直接进入七个学习小功能的子页面练习。
2026-10-13 起「说与写」并入本页，不再是独立的顶部入口。

## banner：七个学习小功能循环卡片

页面顶部是一组自动轮播的卡片（约 6 秒换一张；鼠标悬停或键盘聚焦时暂停，圆点与左右箭头可手动
切换，手机上可左右滑）。每张卡有插画、标题、这项训练是什么、大约多久、计入哪一股，以及**今天的
实际进度**（如「今日 2/10 分钟」「今日已复习 3/20 · 到期 9」）。点卡片即进入对应子页面。

**今日欠账最多的那股会排在最前面**——打开中枢先看见自己缺的那门课；没有进度数据时按固定顺序
（写作工坊 → AI 口语陪练 → 复述训练 → 计时重读 → 听写 → 复习队列 → 选书难度匹配）。

| 卡片 | 练什么 | 计入哪一股 |
| --- | --- | --- |
| 写作工坊 | 自由写作或按等级出题，AI 批改后可不限次修订 | 说与写 |
| AI 口语陪练 | 五个场景与外教对话，逐轮反馈 | 说与写 |
| 复述训练（4-3-2） | 同一段落复述三遍，时限 4→3→2 分钟 | 说与写 |
| 计时重读 | 同一段落朗读三遍，实测语速 | 流利度 |
| 听写 | 听段落逐词打出，词级比对 | 词汇学习 |
| 复习队列 | 到期生词按间隔重复逐张复习 | 词汇学习 |
| 选书难度匹配 | 按词汇量选书架、估生词密度 | 阅读输入（决策，不计分钟） |

## 管理功能卡片（R208）

banner 右上角的齿轮打开「管理功能卡片」抽屉：八个功能逐一勾选，保存后 banner 只轮播
勾选的那些。勾选跟账号走（所有设备一致）；打开页面瞬间按本机缓存先裁剪、随后与
服务端对齐，另一台设备的改动会在下次打开时同步过来。全部取消勾选时 banner 显示
引导卡，点「选择功能」回到抽屉。被隐藏的功能并未关闭——子页面仍可直达，练习时长
照常计入四股；今日计划、复习摘要与本周四股三个面板不受勾选影响。

## 各子页面能做什么

- **复习队列**：到期生词逐张卡片复习，刚学过、昨天学过的词优先出现；题目按熟练度自动升级——
  **四选一**（初学，看中文释义挑出它的英文词）、**近义词题**（初学期随机穿插：给你这个词，
  问下面哪个词跟它意思最接近，答完顺带告诉你两个词的细微差别）、**回忆题**（看释义自己回想，
  点「揭示」对照）、**拼写题**（熟练后看释义拼写，系统判定对错）。四选一和近义词题的错误选项
  是量身挑的：来自你自己的生词、跟你当前词难度相当的词、以及该词的反义词，每次出题重新抽一遍
  ——不会再出现整条队列都是同样三个错误选项这种练了等于没练的题。词卡上还显示「最近在本书第几章
  遇见过它」的原文语境与遇见次数。每次作答按 忘记 / 难 / 想起 / 轻松 四档自评或自动判定，算法
  据此安排这个词下次出现的时间（10 分钟到数周）。今日目标 20 张，达标后仍可继续加练，上不封顶。
- **听写**：播放段落音频（TED 真人音频或 TTS 合成），打出听到的内容，词级 diff 逐词标色
  （对 / 错 / 漏 / 多）；勾选后漏写错写的词一键进复习队列。
- **AI 口语陪练**：五个场景（咖啡店 / 面试 / 旅行 / 闲聊 / 聊在读的书）开聊，教练先回应内容再给
  语言反馈（先鼓励、再纠错、后给更地道的说法）；宽松 / 标准 / 严格三档教练风格。结束出会话报告：
  小结、进步点、你用得好的词、全部纠错。历史会话可点开回放。**支持语音输入**：点麦克风说话，
  识别结果回填输入框，确认或改两个词再发送；可选麦克风设备。**教练回复可自动朗读**（可开关）。
- **复述训练（4-3-2）**：粘贴一段读过的英文，用 4→3→2 分钟的递减时限复述三遍，**可说可打**
  （麦克风识别结果回填，可改后提交）。系统自动算每轮的语速（WPM）、填充词次数、词汇多样性，
  结束 AI 解读三遍的变化并给训练建议。
- **计时重读**：从听力素材里选段（或用「含你到期词的段落」推荐），同一段落朗读三遍，计时器实测
  语速；每轮自动入账流利度股，页面实时显示 首次 / 最佳 WPM 与提升幅度。
- **写作工坊**：自由写作或按 A2–C1 等级出题（可结合你在读的书）。提交后 AI 批改——总体评价 +
  逐句点评 + 「母语者会怎么写」的升级表达 + 四维评分（语法 / 词汇 / 连贯 / 任务完成度）；按批改
  改完可以继续提交，**修订次数不限**（2026-10-21 起），每次都与上一稿对比给「进步确认」。
  长文批改可能需要 1–3 分钟（2026-10-21 R191 起代理等待上限 210s）；同一篇正文原样重试不会多出一稿，
  后端会直接返回上一稿的批改结果。2026-10-21 R194 起批改过程会显示「批改中… 已等待 Ns」的进度；
  即使网络中断，批改仍会继续并在后台保存，刷新写作历史即可看到结果。
  **没写完的下一篇不会丢**（2026-10-13 起）：写作历史每一行都标着状态（还没开始写 / 已交第 N 稿·
  可继续修订），点任意一行就把题目、要求、提示、你上次写到的正文和那次的批改结果一并装回页面，
  接着写；页面顶部还会直接给出「继续上次的写作」，一键回到最近一次写作。注意：**2026-10-13 之前
  出的题，当时的「提示」行没有存档，续写时恢复不了**（题目与要求、你的正文都在）。
- **选书难度匹配**：按你的词汇量自动选定分级书架（阶 1–6，六阶爬梯），再从书架内逐本估算生词
  密度，标出 轻松读 / 正合适 / 挑战读 三档与高频生词预览；推荐书可点击直达书库详情页。估算在
  后台进行，打开页面稍等片刻会自动补上。

## 中枢还告诉你

- **今日计划**：四股时间预算与今日已入账（如「词汇学习 2/10min」）。在阅读器里实际阅读的时长
  （页面可见且有翻页/滚动操作才计）、划词查词、复习作答、口语/写作/复述、跟读/计时重读都会自动
  折算进对应各股；今日新词一并列出。
- **复习摘要**：今日复习进度 x/20、明日到期、已掌握数、7 天保持率，以及「现在有 N 个词到期」。
- **本周四股**：近 7 天各股实际入账的堆叠条（段宽按当日预算归一，右侧显示当日合计分钟）——
  哪天瘸了哪股一眼可见。

## 使用建议

- 释义题干依赖单词详解缓存：查过的词立即有完整题目；没查过的词先以「亮词自评」模式复习，在
  MagicLens 扩展里划词查过一次后自动升级为完整题型（2026-10-09 起阅读器内置划词下线，查词统一
  走扩展）。
- 阅读时随手标记生词，复习队列会自动滚动起来；无需手动录入。
- 统计暂不可用时（后端在重启或降级），计划行与摘要卡会显示「–」或直接隐藏，banner 卡片照常可点。
