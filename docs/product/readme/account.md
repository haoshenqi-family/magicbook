# 账号（account）· 用户手册

## 这是什么

登录后，顶栏和移动底栏的「账号」进入 A1 `/me`。账号域按用户任务拆成 7 页：
页头只显示「账号」和分组纯文字导航，不显示内部层级缩写；每个页面只负责一件事，
不再把资料、伙伴、邮件、设置、积分、成就和导出堆在同一页。

| 编号 | 页面 | 能做什么 | 路由 |
| --- | --- | --- | --- |
| A1 | 资料与身份 | 查看用户名、邮箱与 OIDC 绑定状态；修改界面语言和书籍语言；前往统一账号中心 | `/me` |
| A2 | 伙伴与 AI 伴读 | 领取、切换伙伴，配置悬浮球快捷动作，打开共享 AI 伴读抽屉 | `/buddy` |
| A3 | 站内信 | 查看完整收件箱，展开后标记已读，或全部标为已读 | `/mail` |
| A4 | 阅读与词汇 | 调整难度档位，做词汇量测试/细筛，选择阅读主题，重看使用引导 | `/reading/settings` |
| A5 | 积分 | 查看余额和明细、支付宝充值、购买/兑换积分卡、查看订阅 | `/credits` |
| A6 | 成就 | 查看成就进度、解锁状态并领取奖励 | `/achievements` |
| A7 | 我的学习数据 | 创建加密或非加密导出，查看任务进度并下载文件 | `/me/export` |

## 资料与统一账号

- 本站只展示用户名和邮箱。修改账号资料请点「前往统一账号中心」，在新窗口进入
  `account.haoshenqi.top`；统一账号中心同时服务 MagicBook、Moon Well 等应用。
- 本站注销只结束 MagicBook 会话，**不会**同时结束统一账号中心的 SSO 会话。共用电脑上
  需要彻底退出时，还应到统一账号中心退出。
- 管理入口只对管理员显示。普通用户不会看到积分治理、用户管理等管理页面。
