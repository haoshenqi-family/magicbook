## R208 · banner 小功能管理（2026-10-22）

**用户原话**：每日学习的小功能增加一个管理页面，自由选择出现在每日学习页面的小功能。
不勾选则不会出现在 banner 中。减少用户的选择成本。

**拍板口径**（用户 2026-10-22 三项决策）：

1. 勾选状态存 moon-well 账号级（扩展 learning plan settings，跨设备一致）；
2. 管理界面 = banner 角落齿轮入口 → 抽屉勾选，保存即生效，不跳独立页面；
3. 允许全不勾，banner 位置显示引导卡兜底（引导卡即管理入口）。

**边界**：默认（未配置）全部显示；只管 banner 八张功能卡，今日计划/复习摘要/本周四股
三个面板不动；不做自定义排序（保留「今日欠账最多优先」的自动排序）；隐藏 ≠ 关闭——
子页面 URL 直达仍可用，各功能时长照常计入四股台账。

**验收要点**：齿轮开抽屉、勾选保存后 banner 立即裁剪且刷新后保持；勾选跨设备一致
（账号级）；另一设备改动后本机打开中枢被对齐；全不勾出引导卡且可从引导卡回到抽屉；
保存失败有可见报错（不静默）；未配置用户零变化；老后端（无新字段）时功能退化为
本机镜像但不报错。
