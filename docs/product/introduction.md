# magicbook 产品介绍

> 一个自托管的电子书库，也是一套围绕英语阅读的学习系统。

## 一句话

magicbook 以 Calibre 书库为底座，把「找书 → 读书 → 查词 → 记词 → 复习 → 输出」收进同一个站点：读到哪儿、卡在哪个词、下一步该练什么，系统都替你记着。

## 它解决什么问题

想把英文原版读下去的人，通常会同时打开四五个工具：书库管书、阅读器看书、词典查词、背单词 App 复习、AI 聊天问句子。工具之间互不相识——查过的词要手动抄进生词本，读完的书和练过的词毫无关系，今天该复习什么全靠自己判断。

magicbook 的做法是把这条链路上的数据打通：

- 你在书上标记的生词，**自动**进入复习队列，不需要二次录入；
- 复习题的错误选项，**来自你自己的生词**和与你当前水平相当的词，而不是固定的三个干扰项；
- 每个词都记着「最近在本书第几章遇见过它」，复习时能回到原文语境；
- 阅读时长、查词、复习、口语、写作都会折算进当天的学习预算，一眼看出哪一项落下了。

## 核心模块

| 模块 | 一句话 |
| --- | --- |
| **书库** | 浏览、搜索、筛选、上传、元数据管理，支持 OPDS 订阅与 Kobo 同步 |
| **阅读器** | EPUB / PDF / TXT 在线阅读，进度记忆，段落/整页/整本三层翻译 |
| **词汇** | 生词自动判定、认识/生词标记、生词本、词汇量测试与难度推荐 |
| **每日学习** | 复习队列、听写、AI 口语陪练、复述训练、计时重读、写作工坊、选书难度匹配 |
| **AI 伴读** | 就当前这本书对话，能调用查词/翻译工具，跨书跨会话记住你 |
| **积分与订阅** | AI 功能按 token 计费，支付宝扫码充值，成就徽章 |

## 六件值得说的事

**1. 翻译有三层粒度，不用打断阅读节奏**

鼠标移到段落上点「译」，译文就出现在这一段下方，再点一次收回——处理长难句不必切走。整页可以批量翻；整本书也能翻，按章节拆成任务走后台队列，完成后段落译文自动呈现，进度、取消、失败重试都在。

**2. 朗读是长期缓存，不是每次重算**

同一段落重听零等待，音频按段落长期保留。标题栏的「▶」可以从当前位置起逐段连播整本书，听一段自动接下一段、章末自动翻章，正在读的段落高亮并跟随滚动。管理员还能提前把整本书的音频预生成好，之后所有读者首听即秒开。

**3. 生词判定按词族生效，不是逐词形态**

标记任一词形即覆盖全族，`run / running / ran` 不会各算一个生词。难度档位 0–9 十档（默认 CET4）决定判定密度，随时可调。

**4. 词汇量测试会直接改变你的书架**

3–4 分钟自适应测试，只答「认识 / 不认识」，给出词汇量估算、区间与各频段掌握度，然后推荐适合的阅读难度档位，一键应用。想更精确可以对估算区间再做一轮细筛复测，区间收窄，边界词更多收进生词本。选书时按词汇量给出「轻松读 / 正合适 / 挑战读」三档与高频生词预览。

**5. 每日学习是一个中枢，不是八个孤立功能**

顶部循环卡片按「今日欠账最多」排序，打开就先看见自己缺的那门课。八个训练各自计入四股预算——**词汇学习、阅读输入、流利度、说与写**——本周四股的堆叠条能看出哪天瘸了哪一股。

其中几项值得一提：复习队列的题型会随熟练度升级，从四选一、近义词辨析到回忆、拼写，每次作答按「忘记 / 难 / 想起 / 轻松」四档安排下次出现时间（10 分钟到数周）；口语陪练有五个场景和三档教练风格，先回应内容再给语言反馈，结束出会话报告；复述训练用 4→3→2 分钟递减时限复述三遍，自动算语速、填充词和词汇多样性。

**6. AI 伴读知道你在读什么**

打开阅读页右侧抽屉提问，书名、章节、当前页文本自动作为上下文；AI 可以调用查词、翻译等工具，调用过程以「工具芯片」展示；它会跨书、跨会话记住你的偏好和英语水平。

## 和 MagicLens 词镜的关系

[MagicLens 词镜](https://github.com/haoshenqi-family/magiclens) 是配套的浏览器扩展，把同样的查词、单词详解、生词高亮带到任意网页。

两者共用同一账号与同一份生词本数据，并且会自动避让：装了就由扩展接管，阅读器隐藏自己那份，不会出现同页两个气泡、一个生词两条波浪线；**没装、版本过旧、或你关掉了扩展的高亮，阅读器自带的划词与生词波浪线照常可用**——不装扩展也能查词。

## 适合谁

- **想把英文原版读下去的成人学习者**：需要的不是更多材料，而是一条不会断的复习链。
- **自建书库的重度阅读者**：已经在用 Calibre 管书，希望阅读界面和 AI 能力更顺手。
- **家庭或小团队**：一套书库多人共用，账号、权限、积分各自独立。

## 快速上手

1. 浏览器打开站点，通过统一登录（Authentik）进入，首次使用自动建号。
2. 书架选书进入阅读器；段落点「译」看该段，工具栏「译」翻整页，「整本译」翻全书。
3. 在「阅读设置」里做一次词汇量测试，应用推荐的难度档位。
4. 读到生词随手标记，去「每日学习」看今天的复习队列——它会自己滚起来。

## 技术底座

- 基于 [calibre-web](https://github.com/janeczku/calibre-web) 二次开发，保留原书库结构，AI 能力集中在独立子包中以保持低侵入；
- Python / Flask，Docker 部署，支持 OPDS 与 Kobo；
- AI 支持多 provider、多模型，模型配置在管理后台维护，API Key 加密存储，AI 功能默认关闭需显式启用；
- 与 moon-well 同一账号体系，积分、订阅、成就由后端统一记账（1 千 token = 1 积分）。
