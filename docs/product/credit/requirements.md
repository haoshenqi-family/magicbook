## R242 · 积分卡：购买、兑换与管理员发卡入口（2026-10-28）

**用户原话**：「我想增加一个积分兑换卡服务。我可以发1000 5000 10000积分的积分卡。任何人知道卡的密钥即可兑换。也可以在积分页面买积分卡送人。」

**确认口径（2026-10-28）**：

1. 卡密可以转让给任何人；任何已登录用户持有有效卡密即可兑换。
2. 购卡默认 30 天有效；管理员发卡可设置 1–3650 天或长期有效。
3. 购买积分卡不享受充值倍率活动，买家积分不增加，支付成功只生成卡密。
4. 只做文本卡密与复制，不做二维码、图片、分享海报或邮件。
5. 价格固定：1000 积分 ¥10、5000 积分 ¥50、10000 积分 ¥100。

**本仓范围**：

- 积分页新增兑换框、三档购卡卡、已购卡密列表与复制按钮。
- 购卡复用现有支付宝当面付与订单轮询；支付成功后按订单号定位新卡并提示复制。
- 管理员面板新增批量发卡、批次列表、查看卡密、作废与文本导出。
- `/ajax/credit/card/*` 九条薄代理；管理员接口在本仓先做 `role_admin()` 403 门禁。

**边界**：

- 卡密不绑定手机号/邮箱、不指定受赠人、不做转赠记录链、不退款、不续期。
- 已兑换卡不可作废；过期、作废、已兑换与不存在统一显示上游失败文案。
- 卡密是 bearer secret，本仓不写日志、不落库；页面只提供文本复制。
- 购买者只能查看自己购买的卡；管理员可查看和导出批次卡密。
- 积分明细中 `CARD_REDEEM` 归入获取方向，显示「积分卡兑换」。

**验收要点**：

- 三档价格与面额正确；活动期购卡不乘倍率，支付后买家余额不变且出现一张卡。
- 任意登录用户可兑换有效卡；重复兑换失败；已购列表只显示本人卡密。
- 复制按钮在现代浏览器与降级路径均可用。
- 普通账号直接请求管理员代理返回 403，且不会触达 moon-well。
- 管理员可发卡、查看批次/卡密、作废未使用卡并下载文本附件。

**R242 增补（2026-10-29）**：用户要求卡密复制拆为「复制卡密」与「复制并分享」，由后者生成分享链接；链接打开后必须说明使用方法。分享仍是纯文本，不新增二维码、图片或海报。链接中的卡密放 URL fragment，避免进入服务端请求、反向代理和访问日志；分享页不得自动兑换，已登录用户引导到积分页兑换，匿名用户登录后在积分页恢复卡密。

跨仓同源：moon-well R227（卡表、发卡、兑换与支付结算主责）。PingCode：MB-233（`ahh6wJTz`）。

## R245 · 积分页按功能分区与明细可读性（2026-10-29）

**用户原话**：「积分充值活动，点击发布报错，400 请求体格式错误。积分页功能太多，堆砌太杂乱了。按照具体的小功能且分优化一下。」后续补充：「积分消耗明细项颜色和背景色几乎一样，根本看不出来」。

**需求实质**：

1. 修复管理员发布充值活动时的 HTTP 400，并让发布失败原因在表单附近可见。
2. 积分页按用户任务重新分区，不继续把所有表单、卡片和表格纵向堆叠。
3. 积分明细的获取/消耗方向、金额和条纹行背景必须有足够对比度，消耗项不能再接近「看不见」。

**定稿口径**：

- 一级页签为 `充值 / 积分卡 / 明细 / 管理`；管理仅管理员可见。
- 用户积分页 `/credits` 的卡密页签内分为 `兑换 / 购卡赠送 / 已购卡密`；管理员治理独立在
  `/admin/credits`，内部为 `积分调整 / 充值活动 / 批量发卡`。
- 余额 Hero 提供三个高频任务跳转；分享卡密进入积分页时自动切到积分卡页签。
- 活动时间仍是东八区墙上时间；前端提交前将 `datetime-local` 的 ISO 值规范为 `yyyy-MM-dd HH:mm:ss`。
- 获取态用深绿徽标/金额，消耗态用高对比琥珀底 + 深褐文字；金额加粗，不使用易被条纹背景吞掉的内联浅色。
- 不改变充值、卡密、积分调整、批量发卡的接口契约与权限门禁。

**验收要点**：

- 管理员可通过页面正常发布活动，请求体时间格式不再触发反序列化 400；成功和失败均在行内可见。
- 普通用户只看到用户页三个任务页签；管理 DOM 只存在于 `/admin/credits`，普通用户直接访问返回 403。
- 分享卡密自动进入积分卡页签。
- 明细表的获取与消耗徽标、金额在普通行和条纹行上均可辨认。

**跨仓同源**：moon-well R229（活动时间字段兼容）；上游需求为 R205 充值活动、R209 充值页。PingCode：需求 MB-235（`Nal8mNRY`）、缺陷 MB-21（`xn-uxsjb`）。
