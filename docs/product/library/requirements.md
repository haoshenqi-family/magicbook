## 1. 模块范围

首页入口与书库浏览侧：登录后第一屏（信息架构）、书架侧边栏、书库列表与筛选、搜索入口、书籍详情页的信息组织。阅读器内部交互归 [reading 模块](../reading/interface.md)，学习中枢归 [learning 模块](../learning/requirements.md)。

## 2. 需求条目

### R213 首页信息架构：继续阅读 / 今日计划 / 分级推荐 + 侧边栏分组 + 移动端底部导航

- **来源**：首访体验 QA 报告 §三.2–3.6、§八（`docs/project/qa/2026-10-23/2026-10-23-qa-report.md`，截图 `i1-home-zh.png` / `96-entered.png` / `f1-mobile-home.png`）
- **PingCode**：Ship idea MAGICBOOK-220（Planned）· PJM 工作项 MB-12（用户故事，迭代 1.0）
- **问题（现状事实）**：首页＝「发现（随机四本）+ TED 视频」，无继续阅读、无今日计划、无分级推荐；侧边栏 10 个书架平铺（TED 108 本与分级阶1 的 2 本同级），底部「创建书架」在 900px 视口被裁掉一半；11 个筛选 chips 只有图标无文字；TED 视频卡与电子书卡外观一致；搜索与高级搜索并排重复；移动端无底部导航、无「我的书架 / 继续阅读」。

**应该长什么样**（六条，2026-10-23 定稿）：

1. **首页三模块**：继续阅读（最近在读的书 + 进度，可「回到 37/125」）/ 今日计划（待复习词数 + 写作待办）/ 分级推荐（按难度阶 × 未读规则化推荐）。随机发现降为其中一个模块，不再独占首屏。
2. **侧边栏分组**：书架（用户自建）/ 分级（阶 1..N）/ 媒体（TED 音视频）/ 系统，每组显示计数；「创建书架」按钮在 900px 高度可视口内完整可见。
3. **筛选 chips 补文字标签**：11 个图标 chip 均带文字；窄屏收进「筛选」抽屉，图标单独出现时必须有 tooltip。
4. **卡片格式徽标**：每张卡可区分 EPUB / PDF / TED 音频 / 视频时长 / 原声是否已缓存。
5. **搜索入口去重**：顶栏「搜索」与「高级搜索」合并为一个入口 + 高级筛选面板。
6. **移动端底部导航**：书架 / 学习 / 我的 三个一级入口常驻底部，汉堡菜单只留次要项。

**落地口径（2026-10-23 用户拍板，四问）**：

| 问题 | 拍板 |
| --- | --- |
| 拆单 or 整单 | **拆三单**：A 导航与外壳 / B 继续阅读 / C 今日计划 + 分级推荐（PJM 工作项 MB-16 / MB-17 / MB-18 挂 MB-12 之下） |
| 阅读进度存哪 | **新开 `reading_progress` 表**（不往 `ub.ReadBook` 加列，不与 Kobo 通道共用 `KoboReadingState`） |
| 首页路由 | **新开 `/home`**，`/`（原发现页）保留为回退路径 |
| 今日计划口径 | **暂定「待复习词数 + 写作待办」**；写作待办按 `/ajax/learning/writing/history` 数「今日未完成」（`lastDraftNo == null`），不新建 moon-well 接口 |
| 难度阶来源 | **按书架名解析 `阶N`**（同阶多书架合并，按数字升序）；不新增 Books 字段 |
| `/home` 落点 | **直接作为登录后默认落点**（`config_home_landing` 默认 `true`），保留开关回退 |
| 侧边栏四组判定 | **待定**：`shelf` 表无分类字段，方案见 HLD §7.1（建议新增 `shelf.kind` 列）；「系统」组放什么一并待定 |

**非目标**：不做推荐算法 / 协同过滤；不做首页自定义布局（沿用 R208 banner 管理思路另议）；游客浏览属后台配置开关，不在本条改代码。

**待拍板**（阻塞 A 的落地细节，见 HLD §7.1）：侧边栏分组的判定依据（`shelf` 表无分类字段）、「系统」组放什么。

**验收**：① 登录首屏看到「继续读哪本 + 今天要做什么」；② 次日三步内回到 37/125；③ 1440×900 与 390×844 两档无裁切、无横向滚动；④ 每张卡片能区分媒体类型。
