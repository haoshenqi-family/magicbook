- **边界先钉死**：不渲染任何正文。阅读需要长注意力与大屏，塞进小程序只会得到更差的阅读器；

  而数据本来就在 moon-well（生词本、复习调度、测试、四股台账），网页只是薄代理。直连少一跳、少一处
  会话依赖，代价是要把 `moon-well.haoshenqi.top` 加进小程序后台的 request 合法域名。
