## 1. 用户可见变化

伴读 Agent 处理与 MagicBook 页面、阅读、词汇、每日学习、积分或伙伴相关的问题时，可按需读取随 moon-well 发布的 MagicBook 全功能指南，优先给用户可执行的下一步，而不是只泛泛介绍产品。

该指南不影响：

- 现有伴读工具白名单、用户作用域与写确认门；
- magicbook 前端页面、代理端点、会话与消息结构；
- 现有笔记、记忆、朗读和伙伴功能。

## 2. 消费边界

| 助手可以做 | 助手不能做 |
| --- | --- |
| 说明真实页面路径与控制项 | 替用户点击页面或改设置 |
| 解释学习流程、复习/写作/口语等规则 | 开始或提交测验、整本任务 |
| 调用已注册工具查词、查译文、读写笔记/记忆、朗读 | 调用未注册接口或脚本 |
| 告知价格与倍率以页面为准 | 从记忆编造价格、下单或领取成就 |
| 说明管理员能力所在页面 | 执行用户管理或授予权限 |

## 3. 失败与兼容

- moon-well 关闭 Skill 或白名单未放行时，前端无需变化；助手继续按原提示词回答。
- Skill 加载失败不产生新的 HTTP 契约，不影响 SSE 会话；用户最多看到原有能力边界说明。
- 本轮 magicbook 不加代码、不改模板、不新增代理端点，因此无部署顺序要求。
