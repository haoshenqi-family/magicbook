# R275 · 首页改为复习、数据页改「我」、新增主站入口

## 1. 改了什么

| 项 | 之前 | 现在 |
|---|---|---|
| tabBar 顺序 | 生词本 · 复习 · 词汇量 · 数据 | **复习** · 生词本 · 词汇量 · 我 |
| 登录后落点 | `/pages/notebook/notebook` | `/pages/review/review`（tabBar 第一项） |
| 第四页 | 「数据」= 纯学习数据 | 「我」= 身份卡 + 主站入口 + 学习数据 + 退出 |
| 主站链接 | 只在登录页页脚写死域名 | 「我」页一张卡片，域名取自 `config.siteUrl` |

## 2. 为什么复习放第一

这四个页面里只有「复习」是**每天都有明确下一步**的动作：到期队列是有限的、有终点的，
打开就能做、做完就结束。生词本与词汇量是查询与自测，属于「想起来了才点」。
工具型小程序的打开成本高，首页必须是「不用思考就能开始」的那一个。

对应地把 `pages` 数组里 review 提到 notebook 前面，登录成功后的 4 处 `switchTab` 全部改为
跳复习——否则用户登录完会落在第二屏，看似能用，但每天都要多点一次。

## 3. 为什么「数据」改「我」

这一页本来就同时是账号入口（绑定邮箱、退出登录），只叫「数据」会让新用户找不到换绑位置
（R272 里账号入口只能在页尾，需要在数据页往下滑到底）。改名后结构顺势变成：

```
身份卡（点进账号页）  →  网页版入口  →  「学习数据」小标题  →  四张数据卡  →  退出登录
```

身份卡置顶、退出移到底部（原来是头部右上角一个小胶囊）——「退出」是低频且不可逆的动作，
放在拇指最容易误触的位置不合适。

## 4. 主站入口为什么是「复制链接」

小程序**不能直接调起外部浏览器**。理论上还有 `web-view`，但：

- 网页版走 OIDC 登录，`web-view` 里的会话与浏览器不共享，进去就是登录页，登录完也不一定回得来；
- `web-view` 需要在小程序后台配置业务域名并放置校验文件，属于额外运维面；
- 产品口径本来也是「阅读留在网页」，把它塞进 web-view 只是把网页装进一个更小的框。

所以做成 `wx.showModal` 说明 + `wx.setClipboardData` 复制，用户粘到浏览器即可。
域名只写在 `config.js` 的 `siteUrl`，页面里不再出现字符串——换环境只改一处。

  登录后必须落复习、我页必须有账号与主站入口、主站域名只允许出现在 `config.js`。
- 与 R271/R272/R273/R274 的静态锁一起跑：**27 passed**。
- 全部 `.js` 过 `node --check`、全部 `.json` 过 `JSON.parse`。

## 6. 已知边界

- 小程序内无法统计从「复制链接」跳出去的实际人数（没有外链点击上报），这条路径对数据侧不可见。
- 主站需要浏览器登录态；把链接发给别人不会直接看到内容，仍要对方自己登录。
