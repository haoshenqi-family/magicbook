# AC — R250 管理员运营站内信后台（magicbook）

> 状态：开发完成待验收（2026-10-29）

## A. 入口与权限

- [x] `/admin` 管理页有“运营站内信”入口，仅管理员可见。
- [x] `/admin/mail` 管理员可访问；普通用户与匿名用户不可访问。
- [x] 五个 `/ajax/admin-mail/*` 代理均先校验 `role_admin()`；非管理员 403 且不调用上游。
- [x] moon-well 侧白名单拒绝时，页面显示上游 message。

## B. 发送表单

- [x] 支持“指定用户 / 全体用户”切换。
- [x] 指定用户可按关键词搜索、多选、移除；重复 userId 去重。
- [x] 全体模式明确提示包含管理员本人，并显示独立接口取得的精确人数。
- [x] 标题 1–80 字、正文 1–500 字，实时字数可见。
- [x] 跳转路径为空或从白名单选择；不接受手填外链。
- [x] 预计人数超过 5000 时前端阻止发送并显示错误；5000 人可预览。
- [x] 全体人数未知时阻止预览/发送；编辑标题或正文后不丢失已取得的精确人数。

## C. 预览与发送

- [x] 预览显示标题、正文、按钮文案与精确目标人数。
- [x] 发送前二次确认；发送中按钮禁用。
- [x] 发送确认说明可整批撤回，但不误称发送不可撤销。
- [x] 发送成功显示 campaignId、目标数/成功数，并刷新历史。
- [x] 发送失败保留表单内容并显示上游 message。
- [x] 不把用户名单或正文写入 localStorage/sessionStorage。

## D. 历史与撤回

- [x] 历史按时间倒序分页，显示时间、范围、标题、目标/成功人数、操作人、撤回状态。
- [x] 未撤回批次有撤回按钮；已撤回批次不显示。
- [x] 撤回二次确认明确不可恢复。
- [x] 撤回成功刷新历史当前页与 `MBMail` 未读数。
- [x] 撤回失败显示上游 message，不从界面乐观移除。

## E. 用户侧渲染

- [x] `/mail` 与抽屉 Mail 能显示 `ADMIN_ANNOUNCEMENT` 标题与正文。
- [x] 正文与标题全部用文本节点渲染，不执行 HTML。
- [x] 跳转只允许 `/credits`、`/buddy`、`/achievements`、`/learning`、`/mail`。
- [x] 原三类系统邮件显示不变。
